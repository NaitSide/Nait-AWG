# Обезличенные эталоны экспортов

`awg31.guest.json` и `awg31.conf.txt` получены из двух независимых официальных экспортов, предоставленных для сравнения 19.10.2026. `legacy-010.guest.json` сохраняет структуру экспорта Nait-AWG 0.1.0 для проверки совместимости старых записей.

Все приватные и публичные ключи, PSK, HeaderProtectionKey, сигнатурный пакет, адрес сервера, порт, адреса клиентов, подсеть и имя соединения заменены синтетическими значениями. Сервер `203.0.113.10` относится к диапазону для документации. Предсказуемые тестовые ключи не предназначены для использования в VPN. Фикстуры не являются реальными доступами и не содержат оригинальных конфигураций.

Сохранены наборы полей, типы, отсутствующие/пустые значения, структура JSON и правила DNS/MTU/keepalive. Тесты сравнивают разобранные данные, а не порядок строк и сжатые байты.

Каталог назван по проверенной версии официального исходного кода. Локально установленный AmneziaVPN имеет FileVersion/ProductVersion 5.0.3.0. Версия приложения в момент получения исходных файлов отдельно в протоколе не записана; принадлежность экспортов конкретному бинарнику не установлена.

Источники правил и ограничения: [config-export-0.1.1.md](../../../../docs/config-export-0.1.1.md).
