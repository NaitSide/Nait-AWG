# Nait-AWG

```bash
curl -fsSL https://raw.githubusercontent.com/NaitSide/Nait-AWG/main/bootstrap.sh | sudo bash
```

> **Альфа-тестирование.** Пока используйте панель на отдельном сервере, а не на рабочей VPN-ноде.

Уже развернули AmneziaWG через **AmneziaVPN Self-hosted**, но выдавать доступы через приложение неудобно? Nait-AWG добавляет веб-панель для клиентов: список подключений, выдачу конфигов и QR-кодов, включение и отключение доступа, статистику трафика и экспорт резервной копии.

Установщик добавляет **только панель** к уже работающему AmneziaWG 3.1. Он не устанавливает VPN-движок и не перезапускает его контейнер. Перед установкой проверяет совместимость и останавливается, если что-то не совпадает.

Сейчас поддерживается Ubuntu 24.04 x86_64. Во время установки скрипт предложит найденный публичный IPv4 в квадратных скобках: нажмите Enter, чтобы принять его, или введите правильный адрес вручную. Также понадобится пароль администратора панели. Панель откроется по HTTPS на порту 443 с самоподписанным сертификатом. Порт 443 при необходимости откройте в firewall хостинга.

Если перед запуском появилось `sudo: unable to resolve host`, сервер не может разрешить собственное имя. Это предупреждение выводит `sudo` до запуска установщика. Проверьте `hostname` и `getent hosts "$(hostname)"`. Если вторая команда ничего не выводит, откройте `sudo nano /etc/hosts` и добавьте строку `127.0.1.1 ИМЯ_ИЗ_HOSTNAME`, сохранив запись `127.0.0.1 localhost`. На сервере `az-hel-01` строка будет `127.0.1.1 az-hel-01`.

Резервную копию можно скачать в читаемом JSON или зашифровать паролем. **Восстановление из копии ещё не реализовано.** Не считайте экспорт заменой обычного бэкапа сервера.

Проект находится в активной разработке: установщик и перенос на второй сервер ещё проходят проверку. Исходный код Receiver 0.2.1 включён в проект; доступ к приватному репозиторию не нужен.
