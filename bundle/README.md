# Docker-образ AmneziaWG

`amneziawg-3.1.20260812-linux-amd64.tar.gz` — сохранённый чистый образ серверной установки AmneziaVPN для Linux amd64. Он получен через `docker image save`, не через `docker export` или `docker commit` работающего контейнера. В основе — официальный образ `amneziavpn/amneziawg-go`, дополненный серверным Dockerfile разработчиков Amnezia. Образ сохраняет штатные зависимости, но не writable layer запущенного сервера.

Происхождение зафиксировано при проверке официальной установки 28.08.2026. Повторная проверка архива 06.10.2026 подтвердила SHA-256 архива, манифеста, конфигурации и всех 12 слоёв. Проверка 1399 записей слоёв не обнаружила серверный `awg0.conf`, `clientsTable`, файлы серверных ключей, `.env` или закрытые PEM/OpenSSH-ключи. Это не сканирование всех возможных уязвимостей образа.

Параметры закреплены в `scripts/load-awg-image.sh`:

- SHA-256 архива: `388448f1f24b62961101499f8111a89d0ecca928d7e1b551e3de8524f90fcbdd`.
- OCI manifest: `sha256:946043ed2fd6bd730ad187a7bec96fa158eeb68e555e83896f7cdb33bbfbe8c5`.
- Image config: `sha256:0215368efe8b9507b049f11943f26e132b20a09fa861c2e5a90fadd5854e7d64`.
- `amneziawg-tools v3.1.20260812`; в бинарнике подтверждены параметры AWG 3.1. Эта версия совпала с последним опубликованным релизом tools на дату проверки.
- Версионная строка Go-runtime: `0.0.20250522`. Она не обозначает версию протокола и не является подтверждением соответствия последнему коммиту Go-runtime.

Архив загружается через `docker image load`. Локальный тег `amnezia-awg2:latest` используется только для проверки загруженного образа; контейнеры запускаются по проверенному immutable ID с `--pull=never`. При отсутствии или повреждении архива установка останавливается. Автоматического обращения к Docker Hub нет. При смене версии необходимо отдельно проверить новый образ и обновить архив, хеши и сведения о происхождении; подстановка другого файла под прежним именем недопустима.

В комплект не входят серверные реквизиты, Receiver, Node.js или системные пакеты хоста. Ключи и конфигурацию каждой новой ноды создаёт текущий установщик Nait-AWG. Docker и недостающие системные утилиты устанавливаются из репозитория Ubuntu, как раньше; Node.js и библиотеки панели устанавливаются прежним способом.
