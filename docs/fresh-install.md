# Совместная установка AmneziaWG 3.1 и Nait-AWG

Пункт 2 устанавливает новую VPN-ноду и панель на **Ubuntu 24.04 x86_64**. Предварительно устанавливать сервер через AmneziaVPN или передавать приложению SSH-ключ не нужно. Для SSH-входа на VPS нужны обычные реквизиты провайдера; установщик не изменяет `authorized_keys`.

Перед изменениями проверяются существующие файлы VPN, службы, интерфейсы и все Docker-контейнеры, включая остановленные. Найденная установка не заменяется. Недоступный Docker daemon или остатки Docker/containerd без команды Docker также останавливают установку. Одновременные запуски установщика блокируются.

## Что устанавливается

- Docker и недостающие утилиты из репозитория Ubuntu. Уже установленный, но неработающий Docker автоматически не запускается.
- Официальный серверный образ AmneziaWG для Linux amd64 из архива, включённого в проект. Перед изменением системы проверяется SHA-256 архива; после локальной загрузки — идентификатор, ОС, архитектура и `amneziawg-tools v3.1.20260812`. Docker Hub и сборка образа при установке не используются. [Происхождение, версии и контрольные суммы](../bundle/README.md).
- Контейнер `amnezia-awg2`, интерфейс `awg0`, подсеть `10.8.1.0/24`, отдельный UDP-порт. Пересечение подсети с маршрутами хоста запрещено. Docker перезапускает контейнер после перезагрузки.
- Новые серверные ключи и параметры AWG 3.1. Для `RandomTrailers=on` используются одинаковые S1–S4, совместимые с редактором панели. На сервере junk выключен, клиентские значения записаны отдельно. Начальных клиентов нет.
- Существующий внутренний адаптер управления и веб-панель Nait-AWG. Их установщик, привязка к localhost и проверки совместимости не меняются.

Состояние AWG хранится отдельно в `/opt/naitlab/nait_awg_runtime`, а панель — в `/opt/naitlab/nait_awg`. Закрытые ключи не выводятся в терминал. Конфиг и ключи создаются с правами `600`, каталог состояния — `700`. Пункт 3 не заменяет образ, ключи и конфиг VPN. Контейнер использует привилегированный режим, как серверный AWG в Amnezia; доступ панели к Docker даёт полномочия уровня root и не является изоляцией от администратора сервера.

## Отличие от официального приложения

Используется сохранённый официальный серверный образ AmneziaWG и тот же базовый подход: Docker, `awg-quick`, отдельный интерфейс и NAT внутри контейнера. Но это **установщик Nait-AWG**, не запуск официального приложения и не обещание полной идентичности его установки. Образ поставляется из нашего комплекта, а новые ключи, конфиг и запуск готовит Nait-AWG. Дополнительные контейнеры Amnezia DNS и начальный Admin peer не создаются. AmneziaVPN используется как клиент для гостевого `.vpn`/составного QR; управление сервером — через панель.

Первичные источники:

- [Официальный Dockerfile AmneziaWG](https://github.com/amnezia-vpn/amneziawg-go/blob/master/Dockerfile).
- [Dockerfile серверной установки AmneziaVPN](https://github.com/amnezia-vpn/amnezia-client/blob/dev/client/server_scripts/awg/Dockerfile).
- [Запуск AWG в AmneziaVPN](https://github.com/amnezia-vpn/amnezia-client/blob/dev/client/server_scripts/awg/start.sh).
- [Параметры AmneziaWG](https://github.com/amnezia-vpn/amneziawg-go#configuration).

Архив проверен 06.10.2026. В нём отдельно закреплены хеш OCI-манифеста и хеш конфигурации: разные хранилища Docker могут использовать их как идентификатор образа. Принимаются только эти два проверенных значения. Тег архива используется только для локального поиска после `docker image load`; все запуски выполняются по проверенному ID с `--pull=never`. Если архива нет или проверка не прошла, установка прекращается без попытки скачать другой образ. Docker и системные утилиты по-прежнему ставятся из Ubuntu, Node.js и библиотеки панели — прежним способом. Это независимая поставка VPN-образа, не полностью автономная установка без интернета.

## Запуск и порты

Из полного каталога исходников: `sudo bash install.sh full`. Общая команда из README открывает меню — выберите пункт 2.

Установщик предложит публичный IPv4, свободный TCP-порт панели и UDP-порт VPN (по умолчанию `55424`, если свободен). При активном UFW добавляются правила для выбранных TCP/UDP-портов, политика firewall не сбрасывается. Внешний firewall хостинга нужно настроить отдельно.

Без терминальных вопросов:

```bash
sudo env NAIT_AWG_ACCEPT_FRESH=1 \
  NAIT_AWG_PUBLIC_ENDPOINT=203.0.113.10 \
  NAIT_AWG_PANEL_PORT=23670 NAIT_AWG_VPN_PORT=55424 \
  bash install.sh full
```

Замените пример IPv4 реальным адресом. Для меню без TTY передайте `NAIT_AWG_ACTION=full` вместе с остальными переменными.

## Ошибки и сохранение состояния

Если AWG не прошёл проверку, новый конфиг и ключи не удаляются. Диагностика: `sudo docker logs amnezia-awg2`. Повторный пункт 2 не перезаписывает частичную установку.

Если AWG проверен, а панель ещё не создана, устраните ошибку и выберите пункт 1. Если каталог панели уже создан, проверьте `nait-awg-selfhost.service` и `nait-awg-receiver-selfhost.service`; повторная установка не заменит их автоматически. Полного отката пакетного менеджера Docker или частично созданной панели нет.

Приёмочный тест нужен на отдельном чистом VPS: установка, выдача `.conf`/гостевого `.vpn`, подключение телефона и интернет, перезагрузка, пункт 3 без изменения AWG, повторный пункт 2 без изменений, отказ при существующих контейнерах/занятых портах. Локальные тесты и имитация Docker не заменяют этот тест.
