# GeoIP в Nait-AWG 0.1.4

В режиме **«Всё, кроме выбранных сервисов»** можно включить **«Исключать российские IP-адреса из VPN»**. GeoIP дополняет выбранные сервисы и собственные адреса; весь остальной IPv4-трафик направляется через VPN. Переключатель выключен по умолчанию, в остальных режимах GeoIP не используется.

1. Включите GeoIP: при первом включении панель загрузит список. Для повторной загрузки используйте **«Обновить GeoIP»**.
2. Проверьте источник, дату и количество IPv4-подсетей.
3. Нажмите **«Сохранить»** и импортируйте новый конфиг на устройстве. Уже скачанные конфиги автоматически не меняются.

Кнопка **«Обновить IP»** по-прежнему обновляет сервисы через DNS. GeoIP обновляется отдельно, по запросу, без фоновых заданий. Загрузка нового снимка сама по себе не переключает действующие политики. Персональные настройки могут использовать другой снимок; наследование общих настроек работает как прежде.

## Источник и ограничения

[IPdeny](https://www.ipdeny.com/ipblocks/) предоставляет агрегированный [список российских IPv4-подсетей](https://www.ipdeny.com/ipblocks/data/aggregated/ru-aggregated.zone) и [контрольные суммы](https://www.ipdeny.com/ipblocks/data/aggregated/MD5SUM). Сети классифицируются по стране распределения адресов. Российский сервис может использовать зарубежную инфраструктуру, а на одном российском IP могут работать разные сервисы. Выбранные вручную сервисы остаются полезными для дополнения списка. GeoIP не гарантирует, что приложение перестанет показывать предупреждение о VPN.

Загрузчик использует только фиксированные HTTPS-адреса, ограничивает размер и время ответа, проверяет контрольную сумму, канонические публичные IPv4-подсети, количество и покрытие. Резкие изменения относительно предыдущего снимка отклоняются. При ошибке загрузки или проверки предыдущий рабочий список сохраняется; без успешной первой загрузки включить GeoIP нельзя. Проверки целостности не гарантируют полноту и правильность классификации самого источника.

Кеш хранится в `geoip-ru.json` рядом с базой клиентов. Применённый снимок полностью входит в сохранённую политику и резервную копию; экспорт и восстановление не требуют доступа к IPdeny. Повторить запрос обновления можно через минуту.

DNS из клиентского конфига должен оставаться вне исключений. Если он попал в российские сети (например, Яндекс DNS), сохранение покажет ошибку. Выберите подходящий DNS вне исключений; панель не меняет DNS автоматически. Это ограничение не относится к использованию Яндекс DNS сервером панели для поиска адресов сервисов.

## Размеры и проверка на устройствах

На снимке IPdeny от 5 ноября 2026 года 8664 подсети после точного вычитания дают 21719 маршрутов и около 350 КиБ одного значения AllowedIPs. Смежные и вложенные сети объединяются без включения посторонних адресов. Дополнительные сервисы, локальные сети и endpoint могут изменить итоговый размер.

Лимит `.conf` и закодированного `.vpn` — 1 МиБ; распакованного гостевого JSON — 4 МиБ. Импорт, экспорт и предварительная проверка используют согласованные пределы. QR-коды для раздельного туннелирования остаются недоступны.

Перед постоянным использованием проверьте на своих клиентах:

- импорт `.conf` в AmneziaWG и `.vpn` в AmneziaVPN;
- время включения туннеля и переподключение после смены Wi-Fi/мобильной сети;
- российский и зарубежный сервис, DNS и локальную сеть;
- выключение GeoIP с повторным импортом конфига.

Тесты проекта проверяют генерацию, повторный импорт, обновление, перезапуск, восстановление и прежние режимы. Производительность реальных мобильных клиентов с большим числом маршрутов требует проверки на устройствах. Серверные peer, ядро AmneziaWG и параметры маскировки не изменяются.
